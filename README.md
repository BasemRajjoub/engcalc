# engcalc

Rust/egui desktop app for engineering calculation reports with LaTeX math, plots, and HTML export.

## Stack

- [egui](https://github.com/emilk/egui) — immediate-mode GUI
- [resvg](https://github.com/RazrFalcon/resvg) — SVG rendering

## Build

```sh
cargo build --release
```
